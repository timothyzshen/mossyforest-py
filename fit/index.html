    Fit a model¶

    mossyforest.mf(X, y, module_membership, screen_params=None, select_params=None, final_ntree=500, nodesize=None, num_processors=1, max_modsize=5000, verbose=1, seed=None, compute_interactions=True, shap_backend='shap', use_numba=False, blas_threads=None, screen_cache=None) ¶

    Mossy Forest Feature Selection.

    Matches R's mf().

    Parameters:

    Name Type Description Default
    X pd.DataFrame or array like (n, p)

    Feature matrix. Column names are used when X is a DataFrame.

    		 required
    y array like (n,)

    Outcome. Integer/bool is classification; float is regression.

    		 required
    module_membership dict, list, ndarray, or pd.Series

    Module label per feature. dict: {feature: label}; list/array: aligned with X columns; Series: index = feature names.

    		 required
    screen_params screen_control

    Phase 1 parameters. Default: screen_control().

    		 None
    select_params select_control

    Phase 2 parameters. Default: select_control().

    		 None
    final_ntree int

    Trees in the final prediction RF. Default 500.

    		 500
    nodesize int or None

    Min terminal node size. None means 1 for classification, 5 for regression.

    		 None
    num_processors int

    Parallel workers for RF fitting. Default 1.

    		 1
    max_modsize int

    Module size above which blockwise pre reduction is applied. Default 5000.

    		 5000
    verbose int

    0 = silent; 1 = progress messages; 2 = detailed. Default 1.

    		 1
    seed int or None

    RNG seed. None = random.

    		 None
    compute_interactions bool

    Retain the single shot RF so the TreeSHAP interaction matrix can be computed lazily on first access (via result.interaction_matrix / detect_interaction / plot_potential_interactions). False disables interactions entirely and frees the retained RF. Default True.

    		 True
    shap_backend str

    "shap" (default) or "fasttreeshap". The latter returns identical values (exact mode) and is faster, but requires Python <=3.11 with numpy<2 / shap<0.46 (fasttreeshap's dependency pins have no Python 3.12+ wheels). On a modern stack keep "shap".

    		 'shap'
    use_numba bool

    Use a Numba JIT mean|SHAP| reduction when Numba is installed. Default False.

    		 False
    blas_threads int or None

    Inner BLAS/OpenMP thread cap during parallel sections. None (default) = auto: capped to 1 when num_processors > 1, unrestricted otherwise.

    		 None
    screen_cache None, bool, or str/Path

    Cache Phase 1 (screening) results, which depend only on X, y, module membership, screen_params, nodesize, seed, max_modsize, and shap_backend, NOT on select_params. Lets tuning / CV runs that vary only select_params skip screening. None/False (default) = no caching; True = in process memory cache (this Python session); str/Path = on disk cache directory (persists across sessions). A cache hit returns byte identical survivors.

    		 None

    mossyforest.MossyForest ¶

    Bases: BaseEstimator, TransformerMixin

    Sklearn compatible wrapper around mf().

    Suitable for use in sklearn pipelines. Module membership must be supplied at fit() time because it is data dependent (not a hyperparameter).
